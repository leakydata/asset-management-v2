================================================================================
frmCatQuickLook - build it once, then paste the code below
================================================================================

A UserForm is a .frm plus a binary .frx companion, so it can't be handed over
as importable text the way a .bas can. Building it by hand takes two minutes
and only happens once.

You do not set a single size, position, caption or font in the designer. Drop
the controls on, name them, paste the code. LayoutControls sizes the form and
lays everything out on open, so wherever you dragged them is where they stop
mattering.

--------------------------------------------------------------------------------
1. CREATE THE FORM
--------------------------------------------------------------------------------

In the VBE:  Insert > UserForm

In the Properties window (F4) set ONE property:

    (Name)      frmCatQuickLook

Nothing else. A fresh UserForm defaults to about 240x180, which looks tiny;
the code resizes it on open. The Caption is set by the code too - it doubles
as the status line ("2 record(s) for KR416089", "FAILED: ...").

--------------------------------------------------------------------------------
2. DROP ON THE CONTROLS
--------------------------------------------------------------------------------

Names must match exactly - the code is wired to them. Position, size and
caption do not matter at all.

    Control          (Name)
    ------------------------------------
    TextBox          txtSerial
    CommandButton    btnLookup
    Label            lblRecords
    ListBox          lstRecords
    Label            lblFields
    ListBox          lstFields
    CommandButton    btnCopy
    CommandButton    btnPaste

The two labels are headings and are OPTIONAL - leave either out and the form
closes the gap. lblRecords is the strip naming the record columns; the code
pads it with spaces and sets it to Consolas so it lines up over the list, and
builds it from the same numbers the column widths come from, so the two can
never drift apart.

DO NOT put the controls inside a Frame. A control in a Frame has its Left/Top
measured from the FRAME, not the form, so the absolute positioning lands it in
the wrong place and everything piles up - and MSForms will not let it be wider
than the Frame either. The code checks on open and names any that are affected.
To move one out: cut it (Ctrl+X), click the form background, paste (Ctrl+V).

What you get:

    +- Cat Quick Look - 2 record(s) for KR416089 --+
    | [txtSerial................]  [ Look Up   ]   |
    | DCN      DCN NAME        TYPE STATUS SUB DLR |
    | +- lstRecords ----------------------------+  |
    | | C01913004 DUSHORE SEWER  OWNED ACTIVE.. |  |
    | | C10001501 DUSHORE BOROUGH OWNED ACTIVE. |  |
    | +-----------------------------------------+  |
    | Record detail                                |
    | +- lstFields -----------------------------+  |
    | | SerialNumber      KR416089              |  |
    | | MakeCode          CAT                   |  |
    | | ...                                     |  |
    | +-----------------------------------------+  |
    | [ Copy Row ] [ Paste at Selection         ]  |
    +----------------------------------------------+

The form is sized so all 22 fields fit in lstFields without scrolling.

--------------------------------------------------------------------------------
3. PASTE THE CODE
--------------------------------------------------------------------------------

Right-click the form > View Code, then paste everything below the line.
(Do NOT put this in a normal module - it belongs to the form.)

To change how it looks, change the constants at the top of LayoutControls.
CLIENT_W and CLIENT_H are the only two that matter; every other position is
added to or subtracted from them, so the layout stays consistent whatever you
set them to.

================================================================================
Option Explicit

' One entry per ownership record; each item is the array RecordValues returns.
Private mRows As Collection

' A ListBox grows its own vertical scrollbar once the items overflow, and it
' takes the width out of the columns. Reserve it up front, so the last column
' does not clip at exactly the moment a serial has enough records to scroll.
Private Const SCROLL_W As Long = 18

' A list draws each column's text a couple of points in from that column's
' left edge. lblRecords is shifted by the same amount so the heading sits over
' the text rather than over the edge.
Private Const INSET As Long = 3

'==============================================================================
' Setup
'==============================================================================
Private Sub UserForm_Initialize()
    WarnIfContained
    LayoutControls
    ResetDisplay
End Sub

' Called by CatQuickLook before Show, so selecting a cell that holds a serial
' and clicking the button pre-fills it.
Public Sub SeedSerial(ByVal s As String)
    txtSerial.Text = s
End Sub

Private Sub UserForm_Activate()
    txtSerial.SetFocus
    If Len(txtSerial.Text) > 0 Then txtSerial.SelStart = 0: txtSerial.SelLength = Len(txtSerial.Text)
End Sub

'==============================================================================
' Layout
'
' Everything about the form's appearance is set here rather than in the
' designer, so building it by hand is only ever "drop the controls and name
' them".
'
' THE ORDER MATTERS. The form is sized FIRST, before a single control is
' touched. MSForms will not let a control be bigger than the client area it
' sits in - the request is silently clamped, with no error - so a list asked
' for 484 while the form is still its provisional 240 just comes back narrow.
' Size the room, then the furniture.
'==============================================================================
Private Sub LayoutControls()
    '--- the room -------------------------------------------------------------
    Const CLIENT_W As Long = 500     ' usable width inside the border
    Const CLIENT_H As Long = 484     ' usable height below the title bar

    '--- the furniture --------------------------------------------------------
    Const PAD    As Long = 8         ' margin all the way round
    Const GAP    As Long = 6         ' between stacked controls
    Const ROW_H  As Long = 22        ' serial box and Look Up
    Const BTN_H  As Long = 26        ' Copy and Paste
    Const LBL_H  As Long = 13        ' the two headings
    Const REC_H  As Long = 78        ' records list - about 6 rows
    Const LOOK_W As Long = 92        ' Look Up
    Const COPY_W As Long = 110       ' Copy Row

    Const UI_SIZE   As Single = 11   ' the serial box
    Const LIST_SIZE As Single = 9    ' the two lists

    '--------------------------------------------------------------------------
    ' 1. THE FORM, FIRST AND EXACTLY.
    '
    ' Width/Height are the OUTER size; InsideWidth/InsideHeight are the client
    ' area. The difference is the border and title bar, and it is not knowable
    ' until the form has been given a size - so ask once, measure the
    ' difference, then ask again with it added. InsideWidth is CLIENT_W after
    ' this, to the point, on any Windows theme.
    '
    ' The chrome is a few points either way. Anything outside Trim's range is
    ' not a border measurement, and adding it would throw the form off the
    ' screen - so a bad reading just leaves the plain size in place.
    '--------------------------------------------------------------------------
    Me.Caption = "Cat Quick Look"
    Me.Width = CLIENT_W
    Me.Height = CLIENT_H
    Me.Width = CLIENT_W + Trim0To40(Me.Width - Me.InsideWidth)
    Me.Height = CLIENT_H + Trim0To40(Me.Height - Me.InsideHeight)

    '--------------------------------------------------------------------------
    ' 2. Text, fonts, and the two lists' shape.
    '--------------------------------------------------------------------------
    btnLookup.Caption = "Look Up"
    btnLookup.Default = True         ' Enter in the serial box looks it up
    btnCopy.Caption = "Copy Row"
    btnPaste.Caption = "Paste at Selection"

    SetFont txtSerial, "Consolas", UI_SIZE
    SetFont lstRecords, "Consolas", LIST_SIZE
    SetFont lstFields, "Consolas", LIST_SIZE

    lstRecords.ColumnCount = 6
    lstFields.ColumnCount = 2
    FixedHeight lstRecords
    FixedHeight lstFields

    '--------------------------------------------------------------------------
    ' 3. One content width, used by every row, so all four share a right edge.
    '--------------------------------------------------------------------------
    Dim CW As Long
    CW = CLIENT_W - (PAD * 2)                     ' 500 - 16 = 484

    '--------------------------------------------------------------------------
    ' 4. Down from the top.
    '--------------------------------------------------------------------------
    Dim y As Long
    y = PAD                                       ' 8

    Place txtSerial, PAD, y, CW - LOOK_W - GAP, ROW_H
    Place btnLookup, PAD + CW - LOOK_W, y, LOOK_W, ROW_H
    y = y + ROW_H + (GAP * 2)                     ' 8 + 22 + 12 = 42

    ' PlaceLabel returns the space it used, or 0 when the label was never
    ' added - so the gap closes by itself either way.
    y = y + PlaceLabel("lblRecords", RecordHeader(LIST_SIZE, CW), _
                       PAD + INSET, y, CW, LBL_H, "Consolas", LIST_SIZE)
    Place lstRecords, PAD, y, CW, REC_H           ' 57 .. 135
    y = y + REC_H + GAP

    y = y + PlaceLabel("lblFields", "Record detail", PAD, y, CW, LBL_H)

    '--------------------------------------------------------------------------
    ' 5. Up from the bottom. The field list then takes everything in between,
    '    so changing CLIENT_H only ever grows or shrinks that one list.
    '--------------------------------------------------------------------------
    Dim yBtn As Long
    yBtn = CLIENT_H - PAD - BTN_H                 ' 484 - 8 - 26 = 450

    Place btnCopy, PAD, yBtn, COPY_W, BTN_H
    Place btnPaste, PAD + COPY_W + GAP, yBtn, CW - COPY_W - GAP, BTN_H

    Dim fldH As Long
    fldH = (yBtn - GAP) - y                       ' 444 - 156 = 288, ~22 rows
    If fldH < 60 Then fldH = 60                   ' never collapse to nothing
    Place lstFields, PAD, y, CW, fldH

    '--------------------------------------------------------------------------
    ' 6. Columns, scaled to CW. The one belt-and-braces line: if a list somehow
    '    still did not take the width, scale to what it actually got, so it
    '    shows every column rather than clipping DLR off the right.
    '--------------------------------------------------------------------------
    Dim recW As Long
    recW = CW
    If lstRecords.Width < recW Then recW = lstRecords.Width

    lstRecords.ColumnWidths = RecordColumnWidths(recW)
    If recW <> CW Then
        PlaceLabel "lblRecords", RecordHeader(LIST_SIZE, recW), _
                   PAD + INSET, lstRecords.Top - (LBL_H + 2), recW, LBL_H, _
                   "Consolas", LIST_SIZE
    End If

    Dim fldW As Long
    fldW = CW
    If lstFields.Width < fldW Then fldW = lstFields.Width
    lstFields.ColumnWidths = FieldColumnWidths(fldW)
End Sub

' Positions AND sizes a control in one call.
'
' AutoSize is turned off first because a TextBox, Label or CommandButton with
' it on resizes to its contents and ignores an explicit size. ListBox has no
' such property, hence the guard rather than a plain assignment.
Private Sub Place(ByVal c As Object, ByVal x As Long, ByVal y As Long, _
                  ByVal w As Long, ByVal h As Long)
    On Error Resume Next
    c.AutoSize = False
    On Error GoTo 0

    c.Move x, y, w, h
End Sub

' Positions an OPTIONAL label and returns the vertical space it used, or 0 if
' it was never added. The form lays out correctly either way.
'
' WordWrap goes off explicitly: a Label defaults to wrapping, and the record
' heading is one long space-padded line that would otherwise fold onto a
' second row and sit over nothing.
Private Function PlaceLabel(ByVal nm As String, ByVal cap As String, _
                            ByVal x As Long, ByVal y As Long, _
                            ByVal w As Long, ByVal h As Long, _
                            Optional ByVal fontName As String = "", _
                            Optional ByVal fontSize As Single = 0) As Long
    Dim c As Object
    On Error Resume Next
    Set c = Me.Controls(nm)
    On Error GoTo 0
    If c Is Nothing Then Exit Function

    On Error Resume Next
    c.WordWrap = False
    On Error GoTo 0

    If Len(fontName) > 0 Then SetFont c, fontName, fontSize
    c.Caption = cap
    Place c, x, y, w, h
    PlaceLabel = h + 2
End Function

' The border-and-title-bar allowance, clamped to what a border can plausibly
' be. See LayoutControls.
Private Function Trim0To40(ByVal v As Single) As Long
    If v < 0 Then Exit Function
    If v > 40 Then Exit Function
    Trim0To40 = CLng(v)
End Function

Private Sub SetFont(ByVal c As Object, ByVal nm As String, ByVal pts As Single)
    On Error Resume Next
    c.Font.Name = nm
    If pts > 0 Then c.Font.Size = pts
    On Error GoTo 0
End Sub

' A ListBox with IntegralHeight on rounds its own Height down to a whole
' number of rows, so the bottom edge lands where the font puts it rather than
' where the layout asked. Off means the height sticks.
Private Sub FixedHeight(ByVal c As Object)
    On Error Resume Next
    c.IntegralHeight = False
    On Error GoTo 0
End Sub

' Names any control that was dropped into a container rather than straight
' onto the form. Worth stopping for: a control inside a Frame has coordinates
' relative to the FRAME, so the layout above silently lands it in the wrong
' place, and it cannot be sized beyond the Frame either.
'
' Uses the direct control references, NOT Me.Controls(name). That lookup does
' not reliably reach a control nested inside a Frame - it fails, the error is
' swallowed, and the control is skipped, so the check reported "all clear" for
' exactly the case it exists to catch.
Private Sub WarnIfContained()
    Dim bad As String
    bad = StrayOne("txtSerial", txtSerial) _
        & StrayOne("btnLookup", btnLookup) _
        & StrayOne("lstRecords", lstRecords) _
        & StrayOne("lstFields", lstFields) _
        & StrayOne("btnCopy", btnCopy) _
        & StrayOne("btnPaste", btnPaste)
    If Len(bad) = 0 Then Exit Sub

    MsgBox "These controls are inside a Frame or other container:" & vbCrLf & vbCrLf & _
           "    " & Mid$(bad, 3) & vbCrLf & vbCrLf & _
           "Their Left/Top are measured from the container, not the form, so " & _
           "the layout will be wrong. Cut them (Ctrl+X), click the form " & _
           "background, and paste (Ctrl+V) to move them out - then delete " & _
           "the Frame.", vbExclamation, "Cat Quick Look - form layout"
End Sub

Private Function StrayOne(ByVal nm As String, ByVal c As Object) As String
    If c Is Nothing Then Exit Function
    If Not c.Parent Is Me Then StrayOne = ", " & nm
End Function

'==============================================================================
' The record list's columns
'
' ONE definition. The list's ColumnWidths and lblRecords' padded caption are
' both built from it, so they cannot drift apart - change a column and the
' heading moves with it.
'==============================================================================

' Relative weights, not points: they are scaled to whatever the list ends up
' being, so CLIENT_W stays the only number to change.
'                           DCN  name type status sub dealer
Private Function RecordColumns() As Variant
    RecordColumns = Array(68, 155, 58, 52, 30, 38)
End Function

' What a list this wide has left for columns once the scrollbar and the text
' inset on both edges are taken out.
Private Function ListUsable(ByVal listW As Long) As Long
    ListUsable = listW - SCROLL_W - (INSET * 2)
End Function

' The weights above turned into real point widths for a list this wide.
Private Function ScaledColumns(ByVal listW As Long) As Variant
    Dim w As Variant: w = RecordColumns()
    Dim k As Single: k = ListUsable(listW) / SumOf(w)

    Dim o() As Long
    ReDim o(LBound(w) To UBound(w))
    Dim i As Long
    For i = LBound(w) To UBound(w)
        o(i) = Int(w(i) * k)
    Next i
    ScaledColumns = o
End Function

Private Function RecordColumnWidths(ByVal listW As Long) As String
    Dim o As Variant: o = ScaledColumns(listW)
    Dim s As String, i As Long
    For i = LBound(o) To UBound(o)
        s = s & CStr(o(i)) & " pt" & IIf(i < UBound(o), ";", "")
    Next i
    RecordColumnWidths = s
End Function

' The heading, padded to sit over the columns. Consolas advances 0.55 em per
' character, so a column starting p points along starts Int(p / (size * 0.55))
' characters along.
'
' Each caption is placed at the running total of the widths rather than padded
' out to its own column's width - rounding a column up to a whole character
' six times over is how a heading ends up a column and a half adrift by DLR.
Private Function RecordHeader(ByVal fontSize As Single, ByVal listW As Long) As String
    Dim o As Variant: o = ScaledColumns(listW)
    Dim caps As Variant
    caps = Array("DCN", "DCN NAME", "TYPE", "STATUS", "SUB", "DLR")

    Dim charW As Single: charW = fontSize * 0.55
    Dim s As String, cum As Long, pos As Long, i As Long
    For i = LBound(o) To UBound(o)
        pos = Int(cum / charW)
        If Len(s) < pos Then
            s = s & Space$(pos - Len(s))
        ElseIf Len(s) > 0 Then
            s = s & " "               ' never let two headings run together
        End If
        s = s & CStr(caps(i))
        cum = cum + o(i)
    Next i
    RecordHeader = s
End Function

' Field name wide enough for the longest header - "OwnershipRequestType" is 20
' characters, 99pt at Consolas 9 - and the value takes the rest.
Private Function FieldColumnWidths(ByVal listW As Long) As String
    Dim u As Long: u = ListUsable(listW)
    Dim c1 As Long: c1 = 132
    If c1 > u \ 2 Then c1 = u \ 2
    FieldColumnWidths = CStr(c1) & " pt;" & CStr(u - c1) & " pt"
End Function

Private Function SumOf(ByVal w As Variant) As Long
    Dim i As Long
    For i = LBound(w) To UBound(w): SumOf = SumOf + w(i): Next i
End Function

'==============================================================================
' Look up
'==============================================================================
Private Sub btnLookup_Click()
    Dim serial As String
    serial = CleanId(txtSerial.Text)
    If Len(serial) = 0 Then
        Me.Caption = "Cat Quick Look - enter a serial number"
        Exit Sub
    End If

    ResetDisplay
    Me.Caption = "Cat Quick Look - looking up " & serial & " ..."
    DoEvents

    ' The handler covers the whole body, not just the call. A response shaped
    ' differently to the one expected raises just as readily as the fetch
    ' does, and an unhandled error in a modeless form is a crash dialog.
    On Error GoTo Fail
    Application.Cursor = xlWait

    Dim txt As String
    txt = CatSearch(serial, "")          ' raises on a non-200

    Dim recs As Object
    Set recs = OwnershipRecords(txt)
    If recs Is Nothing Then
        Me.Caption = "Cat Quick Look - unexpected response"
        GoTo Done
    End If
    If recs.Count = 0 Then
        ' The call succeeded and returned nothing - that is a real answer, not
        ' a failure, and worth saying differently.
        Me.Caption = "Cat Quick Look - " & serial & " is NOT in CCAT"
        GoTo Done
    End If

    Set mRows = New Collection
    Dim i As Long, v As Variant
    For i = 1 To recs.Count
        v = RecordValues(recs(i))
        mRows.Add v
        ' One column each, so nothing shifts when a DCN name is long
        lstRecords.AddItem CStr(v(2))                                       ' DCN
        lstRecords.List(lstRecords.ListCount - 1, 1) = CStr(v(11))          ' DcnName
        lstRecords.List(lstRecords.ListCount - 1, 2) = CStr(v(3))           ' OwnershipType
        lstRecords.List(lstRecords.ListCount - 1, 3) = CStr(v(6))           ' Status
        lstRecords.List(lstRecords.ListCount - 1, 4) = YesNo(CStr(v(10)))   ' HasSubscription
        lstRecords.List(lstRecords.ListCount - 1, 5) = CStr(v(14))          ' DealerCode
    Next i

    Me.Caption = "Cat Quick Look - " & recs.Count & " record(s) for " & serial

    ' Setting ListIndex fires lstRecords_Click, which calls ShowRecord - but
    ' only on a CHANGE, and it is already 0 when a one-record serial follows a
    ' one-record serial. Calling it outright costs one redraw and means the
    ' detail list is never left blank.
    lstRecords.ListIndex = 0
    ShowRecord

Done:
    Application.Cursor = xlDefault
    Exit Sub

Fail:
    Application.Cursor = xlDefault
    Me.Caption = "Cat Quick Look - FAILED: " & Err.Description
End Sub

Private Sub lstRecords_Click()
    ShowRecord
End Sub

Private Sub ShowRecord()
    lstFields.Clear
    If mRows Is Nothing Then Exit Sub
    If lstRecords.ListIndex < 0 Then Exit Sub

    Dim v As Variant: v = mRows(lstRecords.ListIndex + 1)
    Dim h As Variant: h = HeaderArray()

    Dim i As Long
    For i = LBound(h) To UBound(h)
        lstFields.AddItem CStr(h(i))
        lstFields.List(lstFields.ListCount - 1, 1) = CStr(v(i))
    Next i
End Sub

Private Sub ResetDisplay()
    Set mRows = Nothing
    lstRecords.Clear
    lstFields.Clear
End Sub

'==============================================================================
' Copy / paste
'==============================================================================

' Whole record as two tab-separated lines (headers, then values) - drops into
' Excel, an email or a ticket unchanged.
Private Sub btnCopy_Click()
    Dim v As Variant
    If Not PickedRecord(v) Then Exit Sub

    Dim h As Variant: h = HeaderArray()
    Dim s As String, i As Long
    For i = LBound(h) To UBound(h)
        s = s & CStr(h(i)) & IIf(i < UBound(h), vbTab, "")
    Next i
    s = s & vbCrLf
    For i = LBound(v) To UBound(v)
        s = s & CStr(v(i)) & IIf(i < UBound(v), vbTab, "")
    Next i

    ' MSForms.DataObject is available because this project has a UserForm.
    Dim d As Object
    Set d = New MSForms.DataObject
    d.SetText s
    d.PutInClipboard

    Me.Caption = "Cat Quick Look - copied all " & (UBound(h) + 1) & " columns"
End Sub

' Writes into whatever cell is selected RIGHT NOW - resolved at click time, so
' it is never stale no matter how much you clicked around while this was open.
Private Sub btnPaste_Click()
    Dim v As Variant
    If Not PickedRecord(v) Then Exit Sub

    Dim c As Range
    On Error Resume Next
    Set c = Application.ActiveCell
    On Error GoTo 0
    If c Is Nothing Then
        Me.Caption = "Cat Quick Look - select a cell in a workbook first"
        Exit Sub
    End If

    On Error GoTo Fail
    Dim n As Long
    n = QuickLookPasteWidth(c.Worksheet)
    QuickLookPasteAt c, v, n

    Me.Caption = "Cat Quick Look - pasted " & n & " cols to " & _
                 c.Worksheet.Name & "!" & c.Address(0, 0)
    Exit Sub

Fail:
    ' A protected sheet is the usual one, and it reads better on the title bar
    ' than as a crash dialog over a floating window.
    Me.Caption = "Cat Quick Look - could not paste: " & Err.Description
End Sub

' TRUE/FALSE -> Yes/No, and a dash when the API didn't return the field at
' all. Absent is not the same as No, so it must not read as one.
Private Function YesNo(ByVal s As String) As String
    Select Case UCase$(Trim$(s))
        Case "TRUE":  YesNo = "Yes"
        Case "FALSE": YesNo = "No"
        Case Else:    YesNo = "-"
    End Select
End Function

' Hands back the selected record, or reports why it can't.
' NOT called Selected: UserForm already inherits a member of that name,
' and redeclaring it is "Member already exists in an object module from
' which this object module derives".
Private Function PickedRecord(ByRef v As Variant) As Boolean
    If mRows Is Nothing Then
        Me.Caption = "Cat Quick Look - look up a serial first"
        Exit Function
    End If
    If lstRecords.ListIndex < 0 Then
        Me.Caption = "Cat Quick Look - pick a record from the list first"
        Exit Function
    End If
    v = mRows(lstRecords.ListIndex + 1)
    PickedRecord = True
End Function
