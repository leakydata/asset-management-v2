================================================================================
frmCatQuickLook - build it once, then paste the code below
================================================================================

A UserForm is a .frm plus a binary .frx companion, so it can't be handed over
as importable text the way a .bas can. Building it by hand takes a couple of
minutes and only happens once.

THE CODE SETS TWO NUMBERS: the form's own Width and Height, and only because
Excel shrinks a UserForm on open on some display setups (usually a machine
scaled to 125% or 150%, or a form drawn at a different DPI to the one it runs
on). They are the FORM_W / FORM_H constants at the top of the code, and they
match section 1 below - change them in one place if you resize the form.

IT ALSO SETS THE TWO LISTS' COLUMNS - ColumnCount and ColumnWidths, in
PinColumns. A ListBox draws only as many columns as ColumnCount says, so at
the default of 1 the record list shows DCNs and nothing else and the detail
list shows field names with no values. Both are filled either way; only the
drawing is missing.

Nothing else is touched. No Left, no Top, no control Width or Height, no Font.
Those stay properties you set in the designer, and the controls stay exactly
where you draw them. Move things around whenever you like; nothing in the code
needs to change.

--------------------------------------------------------------------------------
1. CREATE THE FORM
--------------------------------------------------------------------------------

In the VBE:  Insert > UserForm

In the Properties window (F4):

    (Name)      frmCatQuickLook
    Caption     Cat Quick Look
    Width       511
    Height      498

511 x 498 leaves 500 x 470 of usable space inside the border, which is what
the sizes below add up to. The Caption is replaced at runtime - it doubles as
the status line ("2 record(s) for KR416089", "FAILED: ...").

--------------------------------------------------------------------------------
2. DROP ON THE CONTROLS
--------------------------------------------------------------------------------

Names must match exactly - the code is wired to them. Drop each one anywhere,
then type these in. Nothing here is sacred; it is one arrangement that fits.

    Control          (Name)        Left   Top   Width  Height
    ---------------------------------------------------------
    ComboBox         txtSerial        8     8     386      22
    CommandButton    btnLookup      400     8      92      22
    Label            lblRecords       8    42     484      13   (optional)
    ListBox          lstRecords       8    57     484      74
    Label            lblFields        8   137     484      13   (optional)
    ListBox          lstFields        8   152     484     278
    CommandButton    btnCopy          8   436     110      26
    CommandButton    btnPaste       124   436     368      26

Why those numbers, if you want to move things: 8 all round is the margin.
484 = 500 - 16, so everything full-width ends at 492. btnLookup ends there too
(400 + 92) and so does btnPaste (124 + 368). lstFields just fills what is left
between the heading above it and the buttons below.

--------------------------------------------------------------------------------
3. THE REST OF THE PROPERTIES
--------------------------------------------------------------------------------

    btnLookup     Caption           Look Up
                  Default           True          <- Enter in the serial box
    btnCopy       Caption           Copy Row
    btnPaste      Caption           Paste at Selection
    txtSerial     Font              Consolas 11
                  Style             0 - fmStyleDropDownCombo   (the default)

txtSerial is a COMBOBOX, not a TextBox - type a serial as before, or pick one
of the last 25 you searched for from the dropdown. Keep the NAME txtSerial: a
ComboBox has .Text, .SetFocus, .SelStart and .SelLength just as a TextBox does,
which is every member the code touches, so swapping only the control's type
leaves every line of code below working untouched.

If you would rather not bother, leave it a TextBox. MruLoad does nothing to a
control that has no list and the box keeps behaving exactly as it always has.

    lstRecords    Font              Consolas 9
    lstFields     Font              Consolas 9

ColumnCount and ColumnWidths are NOT in this list - PinColumns sets them, so
there is nothing to type. For the record, what it sets is:

    lstRecords    ColumnCount       6
                  ColumnWidths      71 pt;162 pt;60 pt;54 pt;31 pt;39 pt
    lstFields     ColumnCount       2
                  ColumnWidths      154 pt;266 pt

ColumnWidths must total LESS than the list is wide. The six above come to
417 in a 484pt list, leaving room for the vertical scrollbar that appears
once there are more records than fit - without that slack the last column
clips exactly when a serial has enough records to need scrolling. If you
resize lstRecords, change them in PinColumns rather than in the designer -
the designer values would be overwritten on open.

The two labels are headings, and their captions are NOT yours to type either -
PinColumns sets them. Drop them on, name them lblRecords and lblFields, and
leave the Caption saying Label1; it gets replaced on open.

    lblFields     becomes           Record detail
    lblRecords    becomes           the strip naming the record columns

lblRecords is space-padded to sit over the columns, so it only lines up in a
monospaced font - the code forces it to the LIST_FONT constants to match the
list, and rebuilds the padding from the same six widths the columns use. That
is the whole reason it is in code: the heading and the columns are two halves
of one thing, and keeping them in step by hand is what went wrong before.

Both labels are still optional. Leave either off and nothing breaks.

    +- Cat Quick Look -----------------------------+
    | [txtSerial................]  [ btnLookup ]   |
    | DCN      DCN NAME        TYPE STATUS SUB DLR |
    | +- lstRecords ----------------------------+  |
    | | C01913004 DUSHORE SEWER  OWNED ACTIVE.. |  |
    | | C10001501 DUSHORE BOROUGH OWNED ACTIVE. |  |
    | +-----------------------------------------+  |
    | Record detail                                |
    | +- lstFields -----------------------------+  |
    | | SerialNumber      KR416089              |  |
    | | MakeCode          CAT                   |  |
    | | ...                                     |  |
    | +-----------------------------------------+  |
    | [ btnCopy ]   [ btnPaste                  ]  |
    +----------------------------------------------+

--------------------------------------------------------------------------------
4. PASTE THE CODE
--------------------------------------------------------------------------------

Right-click the form > View Code, then paste everything below the line.
(Do NOT put this in a normal module - it belongs to the form.)

================================================================================
Option Explicit

' One entry per ownership record; each item is the array RecordValues returns.
Private mRows As Collection

' THE ONLY TWO SIZES IN THIS FILE. The form's outer Width and Height, matching
' what section 1 of the notes says to set in the designer. They exist because
' Excel re-sizes a UserForm as it opens on some display setups and the drawn
' size does not survive - so it is set again here, where nothing can undo it.
'
' FORM_W is final. FORM_H is a STARTING height - FitControls then trims the
' bottom up to just under the buttons, so the form ends up as tall as your
' controls actually need and no taller. Setting FORM_H larger than you need is
' therefore harmless; setting it too small is what would clip the buttons.
Private Const FORM_W As Single = 511
Private Const FORM_H As Single = 498

' The font lstRecords is set to in the designer. lblRecords is forced to match
' it, because the heading lines its columns up with padded spaces and that only
' works if the two are the same monospaced font at the same size. If you change
' the list's font in the designer, change these to match.
Private Const LIST_FONT      As String = "Consolas"
Private Const LIST_FONT_SIZE As Single = 9

'==============================================================================
' Setup
'
' PinSize sets the form's size, FitControls stretches the spanning controls out
' to it, PinColumns sets the two lists' columns. Everything else - every Top,
' every Font, the order things sit in - stays a designer property, listed in
' the notes above, and none of it is touched here.
'==============================================================================
Private Sub UserForm_Initialize()
    PinSize
    FitControls
    PinColumns
    MruLoad txtSerial, "SERIAL"      ' fills the dropdown; harmless on a TextBox
    ResetDisplay
End Sub

' Puts the form back to the size you drew it.
'
' Called from Activate as well as Initialize on purpose. Initialize runs before
' the window actually exists, so a shrink applied while the window is being
' realised happens AFTER it - setting the size there alone can be silently
' undone. Activate runs once the window is real, which is where it sticks.
'
' Assigning a size a form is already at is a no-op, so the second call costs
' nothing when the first one worked.
Private Sub PinSize()
    On Error Resume Next
    Me.Width = FORM_W
    Me.Height = FORM_H
    On Error GoTo 0
End Sub

' Stretches what should reach the edges, out to the edges.
'
' This does NOT lay the form out. Every control keeps the Top you gave it in
' the designer, and the order things appear in is entirely yours. All it does
' is the two things that cannot be got right by hand, because they depend on
' the form's real inside size at runtime:
'
'   - the full-width controls all end at one right edge, MARGIN in from the
'     side, instead of stopping short and leaving a band of grey
'   - the form's bottom is pulled up to just under the buttons, so there is no
'     dead space below them
'
' Move a control up or down, make it taller, reorder them - none of that is
' touched. Only Left/Width on the things that span, and the form's Height.
Private Sub FitControls()
    Const MARGIN As Single = 8       ' clear space at the sides and the bottom
    Const GAP    As Single = 6       ' between the serial box and Look Up

    On Error Resume Next

    Dim rightEdge As Single
    rightEdge = Me.InsideWidth - MARGIN

    ' The two lists span the full width.
    lstRecords.Left = MARGIN
    lstRecords.Width = rightEdge - MARGIN
    lstFields.Left = MARGIN
    lstFields.Width = rightEdge - MARGIN

    ' Top row: Look Up sits on the right edge, the serial box takes the rest.
    txtSerial.Left = MARGIN
    btnLookup.Left = rightEdge - btnLookup.Width
    txtSerial.Width = btnLookup.Left - GAP - MARGIN

    ' Bottom row: Copy keeps its width, Paste stretches to the right edge.
    btnCopy.Left = MARGIN
    btnPaste.Width = rightEdge - btnPaste.Left

    ' Headings, if you added them, line up with the lists AND span them.
    '
    ' The Width matters as much as the Left. A Label clips its caption at its
    ' own right edge with no ellipsis and no complaint, so lblRecords drawn
    ' narrower than the list simply loses the end of the heading - it was
    ' stopping mid-word at the S of SUB. Given the full width it cannot.
    '
    ' Set one property per line rather than in a With block: each is then
    ' skipped on its own if the label was never added, which is what makes the
    ' two labels genuinely optional.
    Me.Controls("lblRecords").Left = MARGIN
    Me.Controls("lblRecords").Width = rightEdge - MARGIN
    Me.Controls("lblFields").Left = MARGIN
    Me.Controls("lblFields").Width = rightEdge - MARGIN

    ' Trim the form's bottom to just below the buttons. Subtracting from Height
    ' rather than assigning it keeps the border allowance out of the sum - the
    ' difference between Height and InsideHeight is the chrome, whatever it is
    ' on this machine, and it stays untouched.
    Me.Height = Me.Height - (Me.InsideHeight - (btnCopy.Top + btnCopy.Height + MARGIN))

    On Error GoTo 0
End Sub

' The two lists' columns.
'
' A ListBox stores 10 columns internally no matter what ColumnCount says -
' ColumnCount only controls how many get DRAWN. So at the default of 1 the
' code below fills every column, no error is raised, and you see the first one
' and nothing else. That is what "the list is jumbled" turns out to be.
'
' ColumnWidths must total LESS than the list is wide. The six below come to 417
' in a 484pt list, leaving room for the vertical scrollbar that appears once
' there are more records than fit - without that slack the last column clips at
' exactly the moment a serial has enough records to need scrolling.
'
' The six numbers live in RecordColumns below, and BOTH the list's ColumnWidths
' and lblRecords' heading are built from them - so the heading always sits over
' the columns it names. Change a width there and the heading follows on its
' own; there is no second place to remember.
Private Sub PinColumns()
    On Error Resume Next
    Dim w As Variant: w = RecordColumns()

    lstRecords.ColumnCount = 6
    lstRecords.ColumnWidths = WidthsList(w)
    lstFields.ColumnCount = 2
    lstFields.ColumnWidths = "154 pt;266 pt"

    ' The two headings. WordWrap off matters on lblRecords: a Label wraps by
    ' default, and the heading is one long space-padded line that would fold
    ' onto a second row and stop lining up with anything.
    With Me.Controls("lblRecords")
        .Caption = RecordHeading(w, LIST_FONT_SIZE)
        .Font.Name = LIST_FONT
        .Font.Size = LIST_FONT_SIZE
        .WordWrap = False
    End With
    Me.Controls("lblFields").Caption = "Record detail"

    On Error GoTo 0
End Sub

' The record list's six columns, in points. The one definition.
'                           DCN  name  type status sub dealer
Private Function RecordColumns() As Variant
    RecordColumns = Array(71, 162, 60, 54, 31, 39)
End Function

Private Function WidthsList(ByVal w As Variant) As String
    Dim s As String, i As Long
    For i = LBound(w) To UBound(w)
        s = s & CStr(w(i)) & " pt" & IIf(i < UBound(w), ";", "")
    Next i
    WidthsList = s
End Function

' The heading, space-padded to sit over the columns. It only lines up in a
' monospaced font, which is why lblRecords is set to the same Consolas the list
' uses. Consolas advances 0.55 em per character, so a column starting p points
' along starts Int(p / (size * 0.55)) characters along.
'
' Each caption is placed at the RUNNING TOTAL of the widths, not padded out to
' its own column's width - rounding a column up to a whole character six times
' over is how a heading ends up a column and a half adrift by the time it
' reaches DLR.
Private Function RecordHeading(ByVal w As Variant, ByVal fontSize As Single) As String
    Dim caps As Variant
    caps = Array("DCN", "DCN NAME", "TYPE", "STATUS", "SUB", "DLR")

    Dim charW As Single: charW = fontSize * 0.55
    Dim s As String, cum As Long, pos As Long, i As Long
    For i = LBound(w) To UBound(w)
        pos = Int(cum / charW)
        If Len(s) < pos Then
            s = s & Space$(pos - Len(s))
        ElseIf Len(s) > 0 Then
            s = s & " "               ' never let two headings run together
        End If
        s = s & CStr(caps(i))
        cum = cum + w(i)
    Next i
    RecordHeading = s
End Function

' Called by CatQuickLook before Show, so selecting a cell that holds a serial
' and clicking the button pre-fills it.
Public Sub SeedSerial(ByVal s As String)
    txtSerial.Text = s
End Sub

Private Sub UserForm_Activate()
    PinSize
    FitControls
    txtSerial.SetFocus
    If Len(txtSerial.Text) > 0 Then txtSerial.SelStart = 0: txtSerial.SelLength = Len(txtSerial.Text)
End Sub

'==============================================================================
' Look up
'==============================================================================
Private Sub btnLookup_Click()
    Dim serial As String
    serial = CleanId(txtSerial.Text)
    If Len(serial) = 0 Then
        Me.Caption = "Cat Quick Look - enter a serial number"
        Exit Sub
    End If

    ResetDisplay
    Me.Caption = "Cat Quick Look - looking up " & serial & " ..."
    DoEvents

    Dim txt As String
    On Error GoTo Fail
    Application.Cursor = xlWait
    txt = CatSearch(serial, "")          ' raises on a non-200
    Application.Cursor = xlDefault
    On Error GoTo 0

    Dim recs As Object
    Set recs = OwnershipRecords(txt)
    If recs Is Nothing Then
        Me.Caption = "Cat Quick Look - unexpected response"
        Exit Sub
    End If
    If recs.Count = 0 Then
        ' The call succeeded and returned nothing - that is a real answer, not
        ' a failure, and worth saying differently.
        '
        ' Said in the LIST as well as the caption. Two empty lists and a line of
        ' small text on the title bar reads as "it broke", not as "the answer is
        ' none" - which is exactly how it was read.
        Me.Caption = "Cat Quick Look - " & serial & " is NOT in CCAT"
        lstRecords.AddItem "No records - " & serial & " is not in CCAT"
        Exit Sub
    End If

    Set mRows = New Collection
    Dim i As Long, v As Variant
    For i = 1 To recs.Count
        v = RecordValues(recs(i))
        mRows.Add v
        ' One column each, so nothing shifts when a DCN name is long
        lstRecords.AddItem CStr(v(2))                    ' DCN
        lstRecords.List(lstRecords.ListCount - 1, 1) = CStr(v(11))          ' DcnName
        lstRecords.List(lstRecords.ListCount - 1, 2) = CStr(v(3))           ' OwnershipType
        lstRecords.List(lstRecords.ListCount - 1, 3) = CStr(v(6))           ' Status
        lstRecords.List(lstRecords.ListCount - 1, 4) = YesNo(CStr(v(10)))   ' HasSubscription
        lstRecords.List(lstRecords.ListCount - 1, 5) = CStr(v(14))          ' DealerCode
    Next i

    ' Only remembered now it is known to have found something - a typo that
    ' returned nothing is not worth offering back tomorrow.
    MruAdd "SERIAL", serial
    MruLoad txtSerial, "SERIAL"

    Me.Caption = "Cat Quick Look - " & recs.Count & " record(s) for " & serial
    lstRecords.ListIndex = 0             ' fires lstRecords_Click -> ShowRecord
    Exit Sub

Fail:
    Application.Cursor = xlDefault
    Me.Caption = "Cat Quick Look - FAILED: " & Err.Description
End Sub

Private Sub lstRecords_Click()
    ShowRecord
End Sub

Private Sub ShowRecord()
    lstFields.Clear
    If mRows Is Nothing Then Exit Sub
    If lstRecords.ListIndex < 0 Then Exit Sub

    Dim v As Variant: v = mRows(lstRecords.ListIndex + 1)
    Dim h As Variant: h = HeaderArray()

    Dim i As Long
    For i = LBound(h) To UBound(h)
        lstFields.AddItem CStr(h(i))
        lstFields.List(lstFields.ListCount - 1, 1) = CStr(v(i))
    Next i
End Sub

Private Sub ResetDisplay()
    Set mRows = Nothing
    lstRecords.Clear
    lstFields.Clear
End Sub

'==============================================================================
' Copy / paste
'==============================================================================

' Whole record as two tab-separated lines (headers, then values) - drops into
' Excel, an email or a ticket unchanged.
Private Sub btnCopy_Click()
    Dim v As Variant
    If Not PickedRecord(v) Then Exit Sub

    Dim h As Variant: h = HeaderArray()
    Dim s As String, i As Long
    For i = LBound(h) To UBound(h)
        s = s & CStr(h(i)) & IIf(i < UBound(h), vbTab, "")
    Next i
    s = s & vbCrLf
    For i = LBound(v) To UBound(v)
        s = s & CStr(v(i)) & IIf(i < UBound(v), vbTab, "")
    Next i

    ' MSForms.DataObject is available because this project has a UserForm.
    Dim d As Object
    Set d = New MSForms.DataObject
    d.SetText s
    d.PutInClipboard

    Me.Caption = "Cat Quick Look - copied all " & (UBound(h) + 1) & " columns"
End Sub

' Writes into whatever cell is selected RIGHT NOW - resolved at click time, so
' it is never stale no matter how much you clicked around while this was open.
Private Sub btnPaste_Click()
    Dim v As Variant
    If Not PickedRecord(v) Then Exit Sub

    Dim c As Range
    On Error Resume Next
    Set c = Application.ActiveCell
    On Error GoTo 0
    If c Is Nothing Then
        Me.Caption = "Cat Quick Look - select a cell in a workbook first"
        Exit Sub
    End If

    Dim n As Long
    n = QuickLookPasteWidth(c.Worksheet)
    QuickLookPasteAt c, v, n

    Me.Caption = "Cat Quick Look - pasted " & n & " cols to " & _
                 c.Worksheet.Name & "!" & c.Address(0, 0)
End Sub

' TRUE/FALSE -> Yes/No, and a dash when the API didn't return the field at
' all. Absent is not the same as No, so it must not read as one.
Private Function YesNo(ByVal s As String) As String
    Select Case UCase$(Trim$(s))
        Case "TRUE":  YesNo = "Yes"
        Case "FALSE": YesNo = "No"
        Case Else:    YesNo = "-"
    End Select
End Function

' Hands back the selected record, or reports why it can't.
' NOT called Selected: UserForm already inherits a member of that name,
' and redeclaring it is "Member already exists in an object module from
' which this object module derives".
Private Function PickedRecord(ByRef v As Variant) As Boolean
    If mRows Is Nothing Then
        Me.Caption = "Cat Quick Look - look up a serial first"
        Exit Function
    End If
    If lstRecords.ListIndex < 0 Then
        Me.Caption = "Cat Quick Look - pick a record from the list first"
        Exit Function
    End If
    v = mRows(lstRecords.ListIndex + 1)
    PickedRecord = True
End Function
